This repository collects **public security-audit and bug-bounty reports** by [PALANIT](https://palanit.com). Each report is a security review of a website, web app, MCP server or AI-agent tool — findings, severity and concrete fixes — published in full as a PDF.

> ⚠️ **Responsible disclosure.** Reports are published for transparency and defensive value, after the issues were disclosed to the owner. Nothing here is an invitation to attack any system, and every finding is a passive or authorized review.

## 📁 How it's organized

```
<company-or-domain>/
  <report-title>.pdf
```

One folder per audited company or site; new reports for the same target land in the same folder.
